# TXON Cloud Computing Internship – Task 01

## Host a Static Website on AWS S3

This project is part of my **TXON Cloud Computing Internship**.

### 📌 Task

Host a static personal portfolio website using **Amazon S3 Static Website Hosting**.

### 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Amazon S3
- AWS Bucket Policy

### ☁️ AWS Implementation

The website is hosted on an Amazon S3 bucket with:

- Static website hosting enabled
- Public read access configured using an S3 bucket policy
- Website files stored in Amazon S3
- `index.html` configured as the index document
